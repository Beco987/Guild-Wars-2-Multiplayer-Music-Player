# Guild Wars 2 Multiplayer Music Player (GW2MM)

* **`GW2MM/`**: the current version, a .NET 8 Windows application (`GW2MM-Host.exe` / `GW2MM-Client.exe`) that
  replaces the AutoHotkey scripts and needs no installation. See [GW2MM/README.md](GW2MM/README.md).
* `Midi Player - Server/`, `Midi Player - Client/`: the original AutoHotkey version (v1.6), kept unchanged. Its
  `Data.csv`, `Csv\`, `Midi\` and `Config.txt` work as-is with the new executables.
